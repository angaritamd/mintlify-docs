El primer paso como coordinador es configurar la estructura de tu servicio.

## Modalidades

Define qué modalidades cubre tu servicio: Rayos X, TAC, Ecografía,
Resonancia Magnética. Cada especialista se asocia a las modalidades
para las que está capacitado.

## Pools vs. modalidad exacta

ClicRad soporta dos modelos de rotación:

<Tabs>
  <Tab title="Modelo de pools">
    Los especialistas rotan dentro de un grupo flexible sin asignación
    fija a una sola modalidad. Recomendado para equipos polivalentes.
  </Tab>
  <Tab title="Modelo exacto">
    Cada especialista cubre únicamente las modalidades específicas para
    las que está certificado.
  </Tab>
</Tabs>

## Restricciones y reglas

Configura reglas de descanso mínimo entre turnos, límites de turnos
nocturnos consecutivos y restricciones individuales de cada especialista.
